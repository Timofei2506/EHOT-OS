# 8. Безопасность б/у ноутбука и проверка прошивки (UEFI/BIOS)

Так как целевой ноутбук Lenovo приобретён бывшим в употреблении, необходимо учитывать риски, связанные не только с накопителем, но и с микропрограммным обеспечением.

## Что гарантирует и чего НЕ гарантирует форматирование HDD
- **Гарантирует**: полное удаление прежних ОС, скрытых разделов восстановления, загрузчиков, вредоносного ПО на диске и неизвестных ключей ОС с помощью `wipefs -a` и `sgdisk --zap-all` перед созданием чистой таблицы GPT.
- **НЕ гарантирует**: удаление угроз уровня прошивки (UEFI/BIOS SPI Flash, Intel ME / AMD PSP, встроенные модули вроде **Computrace / Absolute Persistence** или модифицированные переменные NVRAM). Заявлять обратное было бы технически некорректно.

## Обязательные меры безопасности перед и после установки
1. **Сброс и аудит UEFI/BIOS перед установкой**:
   - Выполните сброс настроек BIOS к заводским (`Load Setup Defaults`).
   - Проверьте, нет ли пароля администратора BIOS от прошлого владельца; при отсутствии — задайте собственный пароль на вход в настройки UEFI.
   - Отключите **Computrace / Absolute Persistence** в разделе Security (если присутствует в прошивке Lenovo).
   - Убедитесь, что **Boot Order** не содержит сетевую загрузку `PXE/Network Boot` первой в списке.
   - При наличии старых пользовательских ключей Secure Boot выполните `Reset to Setup Mode` / `Restore Factory Keys`.
2. **Обновление BIOS/UEFI Lenovo**:
   - Рекомендуется проверить наличие официальных обновлений BIOS для точной модели ноутбука на сайте поддержки Lenovo или через Linux-утилиту `fwupdmgr`:
     ```bash
     sudo fwupdmgr refresh
     sudo fwupdmgr get-updates
     ```
   - Устанавливайте обновления BIOS **только** при подключённом зарядном устройстве и исправной батарее.
3. **Чистота цепочки поставок ОС**:
   - Образ базы проверяется по `SHA-256` и GPG-ключу Linux Mint.
   - Не импортируются сторонние сертификаты и скрипты из прежней системы.
   - Используются только официальные репозитории Mint/Ubuntu и подписанный официальный репозиторий AnyDesk (`deb.anydesk.com`).
4. **Конфиденциальность EHOT OS Control и AnyDesk**:
   - Пароли и токены отсутствуют в ISO и репозитории.
   - Любой модуль мониторинга (`ehot-control-toggle`) или удалённого доступа (`ehot-remote-toggle`) владелец может мгновенно отключить локально.
