# 5. Инструкция установки EHOT OS на ноутбук Lenovo (без ОС)

## Шаг 1. Подготовка BIOS/UEFI на б/у ноутбуке Lenovo
Подключите зарядное устройство к ноутбуку. Вставьте флешку **Kingston DataTraveler** и включите ноутбук, сразу нажимая клавишу входа в BIOS/Boot Menu (у Lenovo обычно **F2**, **Fn+F2**, **F1** или маленькая кнопка **Novo** сбоку корпуса; меню выбора загрузки — **F12** / **Fn+F12**).

Рекомендуемые настройки UEFI (подробнее в [`docs/08_SECURITY_AND_FIRMWARE.md`](08_SECURITY_AND_FIRMWARE.md)):
1. Убедитесь, что **Boot Mode**: `UEFI` (если ноутбук очень старый — допустим `Legacy Support`).
2. Проверьте, что **Computrace / Absolute Persistence** отключён (`Disabled`).
3. **SATA Controller Mode**: установите `AHCI` (не RAID/Intel RST).
4. **Secure Boot**:
   - Если неизвестная видеокарта NVIDIA потребует установки проприетарного драйвера (DKMS), проще заранее отключить **Secure Boot = Disabled** либо позже зарегистрировать MOK-ключ при перезагрузке.
5. Сохраните настройки (`F10`) и выберите загрузку с **USB HDD: Kingston DataTraveler**.

## Шаг 2. Запуск Live-среды и установка EHOT OS
1. В загрузочном меню выберите **«EHOT OS 22.3 (Запуск и установка)»** (если экран остаётся чёрным — выберите **«Безопасный режим графики»**).
2. После загрузки рабочего стола запустите ярлык **«Установить EHOT OS»** (или в терминале `sudo ehot-install`).
3. Установщик автоматически просканирует диски и **заблокирует флешку Kingston DataTraveler**, показав ваш внутренний накопитель `~1 ТБ` (модель, серийный номер, размер, `/dev/sdX` или `/dev/nvme0n1`).
4. Проверьте данные диска и для подтверждения полной очистки старых разделов введите **`YES`**.
5. Введите и повторите новый пароль для пользователя **`Regzen`** (права администратора `sudo`).
6. Дождитесь завершения распаковки системы, создания `/swapfile` (4 ГБ) и установки загрузчика GRUB (UEFI + Legacy BIOS).
7. Выключите ноутбук, **извлеките флешку Kingston DataTraveler** и включите ноутбук.

## Шаг 3. Первоначальная настройка после первой загрузки
1. Войдите в систему под пользователем **`Regzen`**.
2. Подключитесь к Wi-Fi (значок сети в правом нижнем углу панели).
3. Если при первом старте ещё не было интернета, обновите драйверы командой:
   ```bash
   sudo ehot-driver-setup
   ```
4. Нажмите на ярлык рабочего стола **«Завершить настройку AnyDesk и Telegram»** (или выполните вручную):
   - Для удалённого доступа: `sudo ehot-remote-setup` (задайте пароль постоянного доступа AnyDesk и при желании укажите доверенный AnyDesk ID).
   - Для Telegram-мониторинга: `sudo ehot-control-setup` (введите токен существующего бота и Chat ID владельца).
5. Установите подписанное расширение Firefox `ehot-monitor@ehotos.local` согласно [`modules/ehot-control/extension/README.md`](../modules/ehot-control/extension/README.md).
6. Откройте **Timeshift** в меню приложений и создайте первую резервную точку восстановления системы.
