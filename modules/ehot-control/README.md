# EHOT OS Control (`ehot-control`)

Лёгкий фоновый модуль мониторинга и уведомлений в существующего Telegram-бота владельца.

## Отслеживаемые события (строго 4 типа)
1. **Начало просмотра YouTube** — через расширение Firefox (`webNavigation` с фильтром домена на уровне API браузера **только** для `youtube.com` и `youtu.be`). История остальных сайтов не запрашивается и не собирается.
2. **Начало скачивания файла** — через `Firefox Downloads API` (`browser.downloads.onCreated`). Передаётся только имя файла и домен источника; содержимое файлов не читается и не записывается.
3. **Включение ноутбука** — через systemd-юнит `ehot-control-boot.service` с ожиданием сети и повторными попытками при подключении Wi-Fi.
4. **Выключение / перезагрузка ноутбука** — best-effort отправка до отключения сети через `ehot-control-shutdown.service` (при отсутствии сети в момент выключения событие честно фиксируется в локальном буфере и доставляется при следующем включении как отложенное уведомление).

## Приватность и безопасность
- Нет кейлоггеров, скрытых скриншотов, записи экрана, чтения содержимого файлов или пересылки паролей.
- Токен бота (`TELEGRAM_BOT_TOKEN`) и `TELEGRAM_CHAT_ID` хранятся в `/etc/ehot-control/secrets.env` (`chmod 600`, владелец `ehotcontrol:ehotcontrol`) и **недоступны** процессу Firefox и обычному пользователю.
- Интеграция с Telegram вынесена в отдельный независимый модуль `agent/telegram_client.py`.
- Владелец может локально отключить или поставить мониторинг на паузу в любой момент командой `ehot-control-toggle` или через меню приложений.

## Подпись расширения Firefox (Unlisted AMO)
Обычный Firefox в Linux Mint требует криптоподпись Mozilla (AMO) для постоянной работы расширений.
Инструкция по бесплатной unlisted-подписи (без публикации в открытом каталоге) находится в [`extension/README.md`](extension/README.md).
