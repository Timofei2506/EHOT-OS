# EHOT OS Automated Safe Installer (`ehot-installer`)

Автоматизированный, но защищённый от ошибок установщик EHOT OS для загрузки с USB-носителя **Kingston DataTraveler 64 ГБ** на ноутбук Lenovo с пустым HDD 1 ТБ.

## Гарантии безопасности при определении диска (`disk_detect.py`)
1. **Не предполагает `/dev/sda`**: при загрузке с USB флешка часто получает имя `/dev/sda`, а внутренний HDD — `/dev/sdb`.
2. **Жёстко исключает USB и загрузочный носитель**:
   - Определяет физическое устройство, с которого загружен Live-образ (`/cdrom`, `/run/live/medium`, `findmnt` + `lsblk -no PKNAME`).
   - Исключает все диски с `TRAN=usb`, `RM=1` (removable), `HOTPLUG=1`, `RO=1`, а также `loop`, `zram`, `sr*`, `dm-*`.
   - Исключает любые накопители меньше `80 ГБ` (по умолчанию), поэтому 64 ГБ Kingston DataTraveler не может быть выбран ни при каких условиях.
3. **Явное подтверждение владельца**: показывает точный путь (`/dev/sdX` или `/dev/nvmeXn1`), модель, серийный номер и объём в ГБ/ТБ; без явного подтверждения удаление разделов не начинается.
4. **Интерактивный пароль для `Regzen`**: пароль задаётся владельцем в момент установки (никогда не зашит в ISO или скрипты).
5. **Универсальная разметка GPT (UEFI + Legacy BIOS)**:
   - Раздел 1: `1 МиБ` `EF02` (`bios_grub`) для поддержки Legacy BIOS загрузки на GPT.
   - Раздел 2: `512 МиБ` `EF00` (`EFI System`, FAT32) для UEFI.
   - Раздел 3: весь остальной объём `1 ТБ` (`ext4`, метка `EHOT_ROOT`).
   - Создаётся `/swapfile` (4 ГБ, `pri=10`) в дополнение к ZRAM.
6. **Первый запуск (`ehot-firstboot.service`)**: после перезагрузки в установленную систему автоматически запускает `ehot-driver-setup` (подбор драйверов NVIDIA, Wi-Fi, Bluetooth, звука) и предлагает владельцу завершить настройку AnyDesk и Telegram-уведомлений.
