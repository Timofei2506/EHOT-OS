# EHOT OS Remote (`ehot-remote`)

Модуль удалённого доступа и помощи на базе **AnyDesk** из официального репозитория `https://deb.anydesk.com/`.

## Важное ограничение этапа установки
AnyDesk **не подключается автоматически к обычному установщику ОС (Live USB)** до завершения установки системы на диск и настройки службы. Сначала выполняется установка EHOT OS на ноутбук Lenovo, и только затем владелец локально запускает мастер `ehot-remote-setup` для активации постоянного доступа.

## Возможности модуля
- **Автозапуск службы**: `anydesk.service` стартует при загрузке ОС (работает на X11 / LightDM и после перезагрузки).
- **Безопасность паролей**: пароль постоянного доступа **не хранится** в ISO, Git-репозитории или скриптах; владелец задаёт его локально при настройке через `sudo ehot-remote-setup`.
- **Уведомление пользователя о подключении**: в шаблоне конфигурации задан режим `ad.security.interactive_access=1` и видимость системного трея, чтобы пользователь на ноутбуке видел подключение.
- **Локальное отключение доступа**: утилита `ehot-remote-toggle` (и ярлык в меню приложений «Удалённый доступ (AnyDesk) Вкл/Выкл») позволяет владельцу в один клик остановить или снова включить службу.
- **Ограничение по ID (ACL, опционально)**: в `ehot-remote-setup` можно указать доверенный AnyDesk ID администратора.
