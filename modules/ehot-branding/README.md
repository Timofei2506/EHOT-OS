# EHOT OS Branding (`ehot-branding`)

Модуль фирменного стиля EHOT OS (чёрно-фиолетовая технологичная игровая эстетика, маскот — енот).

## Принцип без временных заглушек
Согласно ТЗ, финальная фирменная графика подготавливается отдельным дизайнерским ИИ-агентом. В модуле **намеренно не созданы случайные временные логотипы**. Вместо них предусмотрена строгая система слотов и автоподхвата без переписывания кода ОС.

## Что можно заменить в любой момент
- **Логотип**: `assets/logo/logo.png` / `logo.svg`
- **Обои рабочего стола и экрана входа**: `assets/wallpaper/wallpaper.png` (или `.jpg`)
- **Иконки**: `assets/icons/` (наследует `Papirus-Dark` / `Mint-Y-Purple`, переопределяя любые иконки)
- **Экран загрузки (Plymouth)**: `assets/plymouth/logo.png` (если файл не добавлен — отображается чистый чёрно-фиолетовый экран загрузки с индикатором прогресса и текстом `EHOT OS`)
- **Тема оформления**: `assets/theme/EHOT-Dark-Violet/`
- **Иконка меню приложений (Whisker Menu)**: `assets/menu-icon/ehot-menu.svg` (или `.png`)

## Применение новой графики
После помещения файлов от дизайнера в `assets/` выполните:
```bash
sudo bash modules/ehot-branding/scripts/ehot-apply-branding.sh
```
или (на уже установленной системе):
```bash
sudo ehot-apply-branding /путь/к/assets
```
Подробная спецификация форматов и размеров: [`BRANDING_SPEC.md`](BRANDING_SPEC.md).
