# EHOT-USB-Creator-macOS-MfiSerli.command

Безопасный инструмент записи **MfiSerli OS** (публичная редакция) на USB-флешку для macOS
(Bash 3.2+, штатные утилиты: `diskutil`, `shasum`, `dd`, `curl`, `unzip`, `tar`).

## Что делает
1. Находит готовый `mfiserli-os-22.3-xfce-amd64.iso` (или его части `.part.aa/.part.ab`) в
   `~/Downloads` (включая папки `MfiSerli-OS-1.0.0` / `EHOT-OS-v1.0.0`) и проверяет SHA-256.
2. При необходимости **сам докачивает** недостающие ZIP-части из публичного релиза
   `mfiserli-os-v1.0.0` (HTTP/1.1 + автодокачка, устойчиво к обрывам Wi-Fi), склеивает и проверяет образ.
3. Записывает образ на флешку **без sudo** (режим `[2]`, UEFI/FAT32, подходит для флешек 64 ГБ+)
   или через `sudo dd` (режим `[1]`), с проверкой записи 8 МиБ.
4. Защита: внутренний диск Mac (`disk0`), разделы и виртуальные образы жёстко заблокированы.

## Запуск
```bash
bash ~/Downloads/EHOT-USB-Creator-macOS-MfiSerli.command
```
Подсказка: держите Mac подключённым к питанию и не давайте ему спать (`caffeinate -i bash ...`).

## После записи
Загрузите ПК с флешки (Boot Menu: F12 / Fn+F12 / кнопка Novo), на рабочем столе Live-системы
нажмите «Установить MfiSerli OS».
