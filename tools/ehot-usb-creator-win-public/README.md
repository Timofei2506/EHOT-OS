# EHOT-USB-Creator-MfiSerli (Windows)

Графический помощник записи **MfiSerli OS** (Public Edition) на USB-флешку для Windows 10/11 x64.
Тот же проверенный «сырой» движок записи, что и у EHOT OS USB Creator (Kent Edition), но с новым
интерфейсом в фирменном стиле **Dark Glass** и под файлы публичной редакции.

## Возможности
- Тёмный интерфейс с шагами 1-2-3: образ → флешка → запись; перетаскивание `.iso` в окно мышью.
- **Автопоиск образа** в папках программы, рабочего стола и «Загрузок» (предпочитает `mfiserli-os-*.iso` / `.part.aa`).
- Поддержка одиночного `.iso` и многотомных частей `.iso.part.aa/.ab/…` (склеивает потоково, без лишнего места на диске).
- Проверка SHA-256 перед записью (`.sha256` подхватывается автоматически) и **верификация первых 8 МиБ после записи**.
- Список флешек: только съёмные USB ≥ 4 ГБ; внутренние диски исключены. Крупная флешка помечается «★ рекомендую».
- Прогресс с процентами и скоростью (МиБ/с), журнал действий, защита от случайной записи.

## Сборка (из репозитория)
```bash
dotnet publish tools/ehot-usb-creator-win-public/EhotUsbCreatorPublic.csproj \
  -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -o dist-win
# -> dist-win/EHOT-USB-Creator-MfiSerli.exe
```

## Быстрый старт на Windows
1. Скачайте `EHOT-USB-Creator-MfiSerli-win-x64.exe` (и, при желании, `.sha256` рядом).
2. Запустите от администратора (Windows сам запросит повышение прав — приложение требует их
   для прямой записи на физический диск).
3. Шаг 1: образ найдётся автоматически или перетащите `mfiserli-os-22.3-xfce-amd64.iso`
   (или `...iso.part.aa`) в окно. Шаг 2: выберите флешку. Шаг 3: подтвердите и нажмите
   «ЗАПИСАТЬ НА ФЛЕШКУ».
4. После записи: вставьте флешку в выключенный ПК, откройте Boot Menu (F12 / Fn+F12 / Novo)
   и выберите USB; в Live-системе нажмите «Установить MfiSerli OS».

> В этом релизе Windows-помощник публикуется отдельным файлом `EHOT-USB-Creator-MfiSerli-win-x64.exe`
> (не внутри ZIP-частей), поэтому его можно скачать и запустить даже до докачки образа.
